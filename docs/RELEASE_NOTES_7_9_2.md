# Release 7.9.2 — Unified Light Shell & Accessibility

## Purpose

Unify the TalentCopilot application shell, improve sidebar readability, and move the interface toward a lighter enterprise SaaS presentation.

## Improved

- The sidebar now uses the same light blue-gray visual family as the main workspace.
- Navigation labels use high-contrast slate text instead of pale text on white controls.
- Navigation items are compact integrated rows rather than detached white cards.
- The active destination uses a light blue surface, a blue accent bar, and dark blue text.
- Hover, focus, disabled, select, expander, notice, mission, and recommended-next-step states are aligned with the new light shell.
- Brand text and active-mission context remain readable on the lighter sidebar.
- The global application background and header now visually connect the sidebar and main workspace.
- Shared enterprise hero panels use a lighter treatment while preserving the TalentCopilot identity.

## Accessibility

- Normal navigation text uses `#334155` on a near-white surface.
- Active navigation text uses `#0F4CD8` on `#E8F0FF`.
- Sidebar metadata uses darker slate tones rather than low-opacity pale text.
- Focus-visible styles remain clearly identifiable.

## Preserved

- Official Talent Fit scores and ranks.
- Candidate evidence, interview assessments, compensation records, and decision state.
- PDF exports, workflow routes, and navigation behavior.
- Release 7.9.1 HTML-rendering fixes.
