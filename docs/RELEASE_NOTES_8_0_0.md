# Release 8.0.0 — Premium Unified Experience

## Base

- Release: `7.9.2-unified-light-shell-accessibility`

## Delivered experience

This release implements the approved balanced premium direction rather than the all-light shell introduced in 7.9.2.

- The sidebar uses a softened navy gradient instead of near-black or white.
- Navigation labels use high-contrast off-white text and integrated rows.
- The active destination uses an indigo-to-blue treatment with a cyan accent.
- The main workspace uses a light blue-gray background and soft off-white cards.
- Page headers, tabs, metrics, reports and workflow elements share the same visual language.
- Home is now a real data-backed executive dashboard using active and saved project data.
- Navigation counts are no longer concatenated into button labels.

## Data integrity

The release does not modify:

- Official Talent Fit scores and ranks
- Candidate evidence or risk engines
- Interview questions or saved assessments
- Compensation and budget calculations
- PDF exports
- Recruitment workflow state

No invented trend, benchmark or activity value is displayed. Home metrics are derived from current sessions and saved projects.
