# Integration Guide — Release 7.4.2

## Base

Install only on the exact Release 7.4.1 source tree. The installer validates the release marker and hashes of the modified source files before applying the hotfix.

## Streamlit verification

1. Open Interview Intelligence for a candidate whose role has at least seven competencies.
2. Add a competency such as `Vendor Management` and assign an evaluator level.
3. Confirm that the new competency appears immediately on the post-interview radar and remains after save/reload.
4. Enter a structured French answer containing context, responsibility, personal actions, result and a metric.
5. Confirm that STAR evidence completeness is greater than 0% and that relevant follow-up prompts disappear as evidence becomes complete.
6. Leave another answer field empty and confirm the UI displays `not assessed` rather than `0%`.
